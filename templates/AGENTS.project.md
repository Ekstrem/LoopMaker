# AGENTS.md — <Проект>

<Одна строка: что это за продукт.> Путь по инкрементам — `<01-product>/backlog.md`.

Этот файл читают все агенты проекта. Он дополняет `..\AGENTS.md` (корень воркспейса)
и не отменяет прямой просьбы человека. Зоны ролей — в `loop.config.json`.

## 1. Роли и зоны записи

У каждой роли **ровно одна своя папка** (ядро) + узкий служебный набор.

| Роль | Ядро (пишет только сюда) | Служебные файлы |
|---|---|---|
| **PO** | `01-product/`, `02-cjm/` | `5-backlog/chat/po.md` |
| **Architect** | `03-domain/`, `04-architecture/` | `5-backlog/arch/`, `chat/ar.md` |
| **BackEnd** | `6-code/` | `0-issues/`, `5-backlog/back-end/`, `chat/be.md` |
| **FrontEnd** | `8-front/` | `5-backlog/front-end/`, `chat/fe.md` |
| **DevOps** | `7-deploy/` | `tools/`, `.github/`, `5-backlog/devops/`, `chat/do.md` |
| **TestEngineer** | `9-tests/` | `5-backlog/tester/`, `chat/te.md` |
| **TechLead** | — (координатор) | все папки задач `5-backlog/<роль>/`, `chat/tl.md`, `README.md` |

- `README.md` / `CHANGELOG.md` — общие; правим только разделы про свою зону.
- Проверка: `python tools/check_paths.py` (ядро + служебное), `--strict` — только ядро.

**Выход за зону не делаем молча.** Нужен файл в чужой папке — `→ @TL` в свой outbox,
координатор создаёт задачу владельцу. Исключение — человек попросил прямо.

## 2. Задачи

- Один файл = одна задача: `5-backlog/<роль>/<ID>-NNN.md` (см. `templates/task.md`).
- Обязательные поля: `Статус`, `Приоритет`, `Источник`, `Зависимости`; разделы
  `Задача`, `Критерии приёмки`, `Результат`.
- **Статусы:** `Открыта` → `В работе` → `На проверке` → `Закрыта` (или `Отклонена`).
  Синонимы запрещены — по полю `Статус:` работают `tools/stats.py` и синк с Issues.
- **Закрывает владелец.** Координатор верифицирует и пишет «проверено, можно закрывать».
- Статус изменил — обнови таблицу: `python tools/stats.py --write`.

## 3. Чат ролей

- Пишешь только в свой файл: `5-backlog/chat/<роль>.md`.
- Формат — одна строка: `- [YYYY-MM-DD HH:mm] → @КОМУ: текст`.
- Блокер → `@TL`; вопрос по продукту → `@PO`.
- Перед работой читаешь все outbox'ы и берёшь адресованное себе.

## 4. Git

- Коммит начинается с роли: `be:`, `fe:`, `do:`, `te:`, `ar:`, `tl:`, `po:`
  (допустимо `chat(te):`, `docs(do):`). По префиксу guard определяет роль.
- Пушим в `main` сами, но свою зону не расширяем.
- Секреты — не в файлах и не в сообщениях: они остаются в истории и транскриптах.
