# Retro (LoopMaker)

Здесь живут **материалы ретроспектив** и **черновики** к ним. Это внутренняя зона
процессной роли: команда сюда не пишет — читает через ретро-итоги, а не через файлы.

Почему здесь, а не в проекте:
- решения о процессе (PDR, черновики, разборы) принадлежат LoopMaker, а не XDiary;
- в XDiary у ролей есть рабочее дерево и собственные папки — процессные черновики там
  провоцируют «а можно я поправлю»;
- правка одного файла здесь не влияет на прогоны XDiary.

Структура:
- `IT-01-2026-11-07.md` — вход первой итерации (факты, потери, кандидаты, вопросы);
- **Иммутабельность номеров PDR.** Номер присваивается один раз и не переиспользуется: отзыв/замена решения — новый номер + ссылка на старый (случай: PDR-037 был занят «гигиеной секретов», а «вердикт ⇒ закрытие» ошибочно звался тем же номером — вынесено в PDR-040).
- `drafts/` — копии черновиков D-01…D-09 (рабочая версия; в XDiary остаётся копия
  для чтения ролями, но источник правды — здесь).

Правило то же, что и для проекта: **черновик не действует**, пока не принят владельцем
зоны и не имеет проверки (гейт/метрика/тест).
