# Черновики правил (drafts)

Здесь лежат **идеи**, которые ещё не стали правилами. Черновик **не действует**: на него нельзя
ссылаться как на норму, он не подключается к гейтам и не меняет `AGENTS.md`/`RULES.md`/`CI-RULES.md`.

Зачем отдельная папка: за один день появилось 20 решений, и процесс менялся быстрее, чем роли
успевали его исполнять. Теперь идеи копятся здесь, а перевод в правило — отдельное решение
(и, если понадобится, отдельная запись PDR, когда записи разморозят).

## Как заводить

1. Скопируй `TEMPLATE.md` → `D-<номер>-<короткое-имя>.md` (номер = следующий по списку).
2. Заполни: проблема с цифрой/инцидентом, предложение, цена, кого затронет, **как проверить**.
3. Статус: `черновик` — по умолчанию. Меняется только по решению владельца зоны.
4. Если идея уже применяется как практика (без правила) — так и пиши: «применяется», но не «норма».

## Как переводить в правило

Черновик становится правилом, только если одновременно выполнено:

- владелец зоны согласился (явной строкой в чате или в файле);
- есть **проверка**: гейт, метрика или тест (`§18`: правило без гейта — совет);
- указано место нормы (`AGENTS.md` §…, `RULES.md` §…, `CI-RULES.md`) и дата.

Иначе черновик остаётся черновиком — и это нормальное состояние, а не долг.
