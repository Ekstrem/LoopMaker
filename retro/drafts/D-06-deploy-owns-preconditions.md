# Draft: прод-деплой обязан сам обеспечивать свои предусловия

**Предложил:** @TL (2026-11-13)
**Статус:** драфт до ретро (не вводить без согласия владельца)

## Класс

«Неявное предусловие, живущее только на сервере» — вещи, без которых прод-деплой
падает, но которые не создаются самим деплоем и не проверяются до разрушительных шагов.

## Реальные случаи (4 инцидента за сутки)

- сеть `xdiary`;
- `gen-hosts.py`;
- `update.sh`;
- `.xdiary-*-sh.sha256` (эталон сторожа).

## Предлагаемая норма

Прод-деплой **сам обеспечивает** свои предусловия (сеть / файлы / эталоны) **или
падает до разрушительных шагов** (до штрихов/перезаписи), а не молча в середине.
Патч №27 реализует это для сети.

## Не вводим до ретро

Владелец: «не вводить новые правила, но записывай драфты». Этот драфт — только запись.
