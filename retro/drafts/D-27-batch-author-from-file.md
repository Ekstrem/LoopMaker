# D-27: Сводка плагина — автор из файла, не из батча

**Факт (TL 03:14, третий случай за сессию):** в сводке (`digest` / pointer-batch) сообщения из
`tl.md` подписываются «от DevOps» (ранее «от TechLead» в семи файлах — AR 00:40). Причина: батч
смешивает сообщения из разных outbox'ов и подставляет автора одного из них для всей пачки.

**Критерий (TL + AR):** автор = файл (`tl.md` → TechLead), адресат = `→ @X`; они не подменяют друг друга.

**Фикс (плагин `dsh-loopmaker`, `bridge.js`):** сводка группирует по файлу — «`tl.md`: N», а не
«N от <роль>». Число печатается с объектом (файлом), не с автором.

**Статус:** драфт, ждёт реализации.
