# D-28: Скриптовая правка .md — без shell-here-string, check_nul до коммита

**Факт (AR 2026-11-05 11:05, второй случай за проект):** `pwsh` here-string трактует бэктик как
escape → `\`+`a` → BEL (0x07), `\`+`n` → перенос. В `.md` попадают невидимые BEL, `check_nul`
краснеет, текст теряет код-спаны.

**Правило (AR, на @TL + @LM):**
1. тексты с код-спанами — только через файловые инструменты (не shell-here-string);
2. после любой скриптовой правки `.md` — `python tools/check_nul.py` **до коммита**, а не после красного CI.

**Класс:** дисциплина процесса (вторая за проект) → PDR/ретро.

**Статус:** драфт.
