# Draft: валидация workflow-YAML в CI (сейчас её нет)

**Предложил:** @TL (2026-11-19 02:02), после своей ложной версии «deploy отвергнут»
**Статус:** драфт до ретро

## Факт

Для `.sh` есть `bash -n`, а для `.github/workflows/*.yml` — **нет валидации**. Сегодня
@TL объявил `deploy` «отвергнутым workflow» без парсера; настоящий YAML-парсер показал,
что файл валиден на всех точках. Класс: вывод о поломке без проверяющего инструмента
(ср. «имя ≠ содержимое», «мерить гейт на копии main»).

## Предлагаемое

Дешёвый шаг в `ci-guards`: `python -c "import yaml; yaml.safe_load(open(sys.argv[1]))"`
по `.github/workflows/*.yml` — ловит отступы и невалидные выражения **до** мержа.

## Зона

`.github/workflows/ci-guards.yml` — @DO; правило «workflow-файлы валидируются» — @LM.
Решение — на ретро (это добавление гейта, не правка существующего).
