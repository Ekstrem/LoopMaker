# PDR-033: Общий адаптивный пайплайн микросервисов (Team Topologies)

- **Статус:** Предложено (владельцу)
- **Дата:** 2026-11-05
- **Автор:** @LM (по запросу владельца)
- **Зона:** @DO (инструменты/CI) + @AR (архитектура)

## Проблема

Build/test/publish каждого микросервиса — отдельный workflow `ci-<сервис>.yml` (**15 файлов**),
на ~70% copy-paste (`journal` vs `catalog`: 72 из ~100 строк различаются только именем/путями/образом).
Каждый новый сервис, каждый гейт, каждый шаг деплоя — отдельная DO-задача (`DO-058…083`, 25+).

## Причинность

Корень — нет единой платформенной точки. Логика `restore → build → test → publish` дублируется
в каждом `ci-*.yml`, потому что нет reusable-механизма, куда сервис передаёт только свои параметры.
«Задача на шаг» — следствие: чтобы изменить шаг, правят N файлов и заводят N карточек.

## Варианты

1. **Оставить как есть** — 15 копипаст-файлов, задача на шаг. Дёшево сейчас, дорого в росте.
2. **Reusable workflow** — один `ci-service.yml` (`workflow_call`) + манифест сервиса. Рекомендуется.
3. **Matrix в одном workflow** — все сервисы в одном `ci.yml` через `strategy.matrix`. Минус: один
   красный сервис = один большой прогон; сложнее с разными тестами/контекстами сборки.

## Решение (предложение)

**Вариант 2:** общий `ci-service.yml` + манифест сервиса (`6-msa/services.yaml` или per-service
`service.yaml`): `name`, `path`, `image`, `test-projects`, `api-tests`. Per-service обёртка
`ci-*.yml` = 5 строк (вызов общего с параметрами). `deploy.yml` уже общий — не трогаем.

## Критерий готовности

- Новый сервис добавляется **только манифестом** (+ обёртка 5 строк), без копипаста сборки.
- Изменение логики сборки/тестов — правка **одного** файла (`ci-service.yml`).
- Все 15 сервисов проходят сборку/тесты/публикацию через общий workflow (прогон на норме + на дефекте).

## Связанные решения

- **ADR-028** (граница тестов: тест в папке сервиса) — манифест учитывает `*Tests*` в папке сервиса.
- **D-12** (гейт подключён ≠ написан) — общий пайплайн тоже гейт: два прогона (дефект + норма).
