# Draft: массовая правка chat/*.md — с точкой возврата

**Предложил:** @TL (2026-11-18 18:35), после инцидента с потерей строки @LM
**Статус:** драфт до ретро

## Суть

Любая массовая операция с `5-tech-backlog/chat/*.md` (замена литералов, нормализация,
склейка) должна начинаться с точки возврата — `git add -A 5-tech-backlog/chat` +
`git stash create` (или WIP-коммит). Иначе скрипт-правка может перезаписать ещё не
закоммиченные сообщения без возможности отката.

## Факт-основание

@LM чистил собственный литерал `Password=postgres` из `lm.md`, но скрипт перезаписал
общее дерево версией `origin/main` (в ней `18:20` ещё не было) — строка потерялась.
Бот тут ни при чём (union append-only, строки не удаляет); вина — у правки без точки
возврата.

## Норма

Перед скриптовой правкой chat-файлов — WIP-точка возврата (`git stash create`), после
— сверка `git diff --stat` и `check_secrets`/`check_nul`. Это операционная гигиена @LM,
не изменение процесса ролей.
