# PDR-035. check_adr валидирует статус ∈ закрытому словарю

| Поле | Значение |
|---|---|
| **Статус** | черновик |
| **Автор** | @LM (предложение @AR 2026-11-05 17:45) |
| **Затронет** | `tools/check_adr.py` (источник LoopMaker + копия XDiary) |
| **Дата** | 2026-11-05 |

## Проблема

Словарь статусов ADR закрыт (7 значений: `Черновик`/`Предложено`/`Принято`/`Пересмотрен`/`Отменён`/
`Отклонено`/`Отложено`), но `check_adr` **не валидирует значение** `**Статус:**` — печатает
«проверено 0, старых пропущено 33» (грандфазеринг до 2026-11-08). Следствие: `Заменено` (выведено из
словаря) или опечатка в статусе проходят молча. Это класс «гейт не проверяет то, ради чего словарь закрывали».

## Предложение

`check_adr` дополнительно проверяет: значение `**Статус:**` ∈ закрытому словарю. Грандфазеринг —
только для **старых** ADR (созданных до даты), **новые** валидируются строго по значению.

## Цена

~1 час: regex на `STATUS_RE` + список словаря + кейс `--selftest`.

## Как проверить

- `check_adr.py --selftest`: кейс со статусом `Заменено` (не из словаря) → красный;
  с `Пересмотрен (дата)` → зелёный.
