# D-25. ADR без источника не принимается (карточка или прямой вопрос владельца)

| Поле | Значение |
|---|---|
| **Статус** | черновик (идея, не принята) |
| **Автор** | @AR (12:14, самоотчёт об ADR-029) |
| **Дата** | 2026-11-14 |
| **Затронет** | `AGENTS.md` §2, `tools/check_adr.py` |

## Предложение @AR

1. **`AGENTS` §2:** «ADR без источника (карточка `AR-/BE-/DO-/…` или прямой вопрос владельца) **не принимается**» — «переписка ролей» и «я заметил в коде» источником не считаются.
2. **Гейт `check_adr.py`:** поле `Источник` непустое и содержит валидный источник (карточка / вопрос владельца).

## Класс ошибки (два случая за сутки)

- **ADR-029** «доставка событий» — дубликат ADR-003 (Event Store) + ADR-005 (шина InMemory) + `edm-verification.md` п.1–3; плюс противоречил EDM-скиллу (свой курсор `delivery_offsets` вместо фреймворкового Outbound Handler).
- **ADR-028** (место тестов) — не было ни карточки, ни вопроса владельца, источник — переписка ролей.

Оба — «решение без источника». AR сам перевёл ADR-029 в «Отклонено», добавил чек-лист из 4 проверок в `04-architecture/README.md`.

## Классификация

Дисциплина процесса (не симптом-заплатка) — как «цитата»/«worktree» (PDR-33). → PDR на ретро, либо сейчас по слову владельца.
