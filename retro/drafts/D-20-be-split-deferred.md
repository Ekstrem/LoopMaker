# D-20. Разбиение @BE на 3 роли — отложено до конца E1

| Поле | Значение |
|---|---|
| **Статус** | черновик (идея, не принята) |

| **Затронет** | @BE, `loop.config.json`, `check_paths.py`, `AGENTS.md` §1, `chat/` |
| **Дата** | 2026-11-11 |

## Проблема (зачем это вообще)

`6-msa` (12 сервисов + шлюз) — одна зона одной роли @BE, и она стала узким местом: @BE в одиночку
держал `BC-Client`, `BC-Journal`, `BC-Partners` + шлюз, три блокера шли последовательно, а не параллельно.

## Предложение (@TL, 01:00)

Разбить @BE по bounded contexts, не по слоям: **@BE-Core** (Journal/Partners/Catalog), **@BE-Identity**
(Client/Privacy/Portability/ApiGateway), **@BE-Data** (Somatic/DailyMetrics/Garmin/AppleHealth/Analytics).
Плюс: общие папки — владелец @BE-Identity, контракты — только с ревью @AR; один BC = одна роль (машинно);
кросс-ревью между be-ролями.

## Почему ОТКАЗАНО сейчас (оценка риска @LM, владелец согласился)

Разбиение посреди активного техдолга EDM — **смена зон на ходу**: E1 (пилот Journal+Partners) как раз
в `BC-Journal` + `BC-Partners`, которые по схеме уходят в @BE-Core. Разбить сейчас = резать активную
работу (незакрытый E1 переедет под новую роль посреди пилота) + 3 новые зоны надо закрепить машинно
(`loop.config.json`, `check_paths.py`, префиксы коммитов), а это тянет за собой ревизию гейта `guard-paths`
в момент, когда все роли заняты.

**Вердикт: отложить до конца E1** (пилот доказан, зоны стабильны). Не «забыть» — вернуться, когда E1 закрыт.

## Что делать при возврате (чек-лист)

1. Схема ID задач: три папки `5-tech-backlog/{back-end-core,back-end-identity,back-end-data}` (не один под-тег).
2. Префиксы коммитов: `be-core:` / `be-identity:` / `be-data:` (иначе `check_paths` не различает).
3. Общие папки: `6-msa/XDiary.Contracts`, `ApiGateway` — владелец @BE-Identity; изменение контрактов — ревью @AR.
4. `check_paths.py` + `loop.config.json`: `6-msa/BC-*` → ровно одна be-роль.
5. `chat/`: три outbox'а + правило «`→ @BE-*` в чужой outbox не пишем».
6. PDR-31 — само решение разбиения (варианты + протокол).
