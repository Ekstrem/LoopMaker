# D-29: Литерал ключа хранилища — в одном месте, не дублируется в спеках

**Факт (TE 2026-11-05 08:42):** ключ хранилища `xdiary.accessToken` встречается **30 раз в 13 файлах**
спеки. Это не «стиль», а класс «единый источник правды»: одна переименованная строка ломает половину набора.

**Правило:** литерал (ключ хранилища, имя токена) живёт в **одном месте** — `8-front/js/api.js:8`
(`ACCESS_KEY = "xdiary.accessToken"`); спеки ссылаются на него, а не дублируют.

**Гейт (дёшево):** grep по `9-tests/**` на литерал + allow-list на `api.js`; находка вне allow-list = ошибка.

**Класс:** единый источник правды (тот же, что канон-маркер D-27, но для литералов).

**Статус:** драфт, ждёт реализации гейта.
