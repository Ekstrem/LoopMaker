# Knowledge Base — петля (механика LoopMaker)

Записи **про петли**: как устроен и ломается сам механизм (чат-транспорт, сессии,
конфиг плагина, worktree'и, git-поток, бот) — на реальных инцидентах из проекта
XDiary, который служит полигоном. Каждая запись обязана отделять **факт**
(проверено) от **гипотезы** (предположение) — иначе KB становится источником новых
ошибок, а не защитой от них.

## Формат записи

- Метаданные (дата, статус, роль, проект).
- Симптом.
- Корневые причины (проверенные, каждая отдельно).
- Действия.
- Ошибки и уроки.
- Открытые вопросы.
