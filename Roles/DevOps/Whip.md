# Whip — кнут

> Кнут возвращает роль к правилам и цели закрытия, когда метрика отклоняется.
> Универсальный кнут чата (формат/будущая метка/фантом) — в `RULES.md` §23 и `AGENTS.md` §4.

**Цель:** все задачи → `Закрыта` (критерии + CI зелёный), роль работает по `RULES.<Роль>.md`.

**Метрика:** серверные правки в репо + ранбук = ADR + нет секретов
**Инструмент:** `git status` + `check_secrets.py` + diff ранбук/ADR

**Триггер кнута:** серверная правка не в репо / ранбук расходится / секрет в доке
**Текст кнута:** `→ @DO: серверная правка не в репо / ранбук расходится / секрет — дрейф, закоммить`
