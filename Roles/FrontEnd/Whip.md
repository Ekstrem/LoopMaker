# Whip — кнут

> Кнут возвращает роль к правилам и цели закрытия, когда метрика отклоняется.
> Универсальный кнут чата (формат/будущая метка/фантом) — в `RULES.md` §23 и `AGENTS.md` §4.

**Цель:** все задачи → `Закрыта` (критерии + CI зелёный), роль работает по `RULES.<Роль>.md`.

**Метрика:** `APP_VERSION` + `CACHE` бампнуты парой при изменении `8-front`
**Инструмент:** `git diff -- 8-front` + grep `APP_VERSION`/`CACHE`

**Триггер кнута:** `8-front` изменён, версия не бампнута парой
**Текст кнута:** `→ @FE: 8-front изменён, а APP_VERSION/CACHE не бампнуты парой — SW отдаст старый код`
