# Whip — кнут

> Кнут возвращает роль к правилам и цели закрытия, когда метрика отклоняется.
> Универсальный кнут чата (формат/будущая метка/фантом) — в `RULES.md` §23 и `AGENTS.md` §4.

**Цель:** все задачи → `Закрыта` (критерии + CI зелёный), роль работает по `RULES.<Роль>.md`.

**Метрика:** каждый критерий = selftest-кейс + гейт подключён (2 прогона)
**Инструмент:** `--selftest` + CI + `git diff -- 9-tests`

**Триггер кнута:** критерий без selftest-кейса / гейт без двух прогонов
**Текст кнута:** `→ @TE: критерий без selftest-кейса / гейт без двух прогонов — критерий = кейс в том же коммите`
