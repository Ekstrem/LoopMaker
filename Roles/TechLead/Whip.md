# Whip — кнут

> Кнут возвращает роль к правилам и цели закрытия, когда метрика отклоняется.
> Универсальный кнут чата (формат/будущая метка/фантом) — в `RULES.md` §23 и `AGENTS.md` §4.

**Цель:** все задачи → `Закрыта` (критерии + CI зелёный), роль работает по `RULES.<Роль>.md`.

**Метрика:** нет простоя ролей + доска = `.md` + факты из `origin`
**Инструмент:** `whip.py` + `sync_board --check` + `git show origin/main:`

**Триггер кнута:** роль простаивает / доска расходится / факт не из `origin`
**Текст кнута:** `→ @TL: роль X простаивает / доска расходится / факт не из origin — исправь или эскалируй`
