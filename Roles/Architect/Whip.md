# Whip — кнут

> Кнут возвращает роль к правилам и цели закрытия, когда метрика отклоняется.
> Универсальный кнут чата (формат/будущая метка/фантом) — в `RULES.md` §23 и `AGENTS.md` §4.

**Цель:** все задачи → `Закрыта` (критерии + CI зелёный), роль работает по `RULES.<Роль>.md`.

**Метрика:** ADR не изменился содержательно (кроме статуса + «Заведённые задачи»)
**Инструмент:** `check_adr_frozen` (hash тела, PDR)

**Триггер кнута:** hash тела ADR расходится (содержание изменено)
**Текст кнута:** `→ @AR: ADR-XXX изменён содержательно — старый ADR только статус, уточнение = новый ADR`
